紹介プライバシー利用規約

名刺を撮る。整える。あとで迷わない。

aftercardは、名刺を撮影または写真から読み取り、名前・会社・電話・メール・住所などをタグ付きの連絡先として保存するiPhoneアプリです。

文字認識は端末内で行います。画像と読み取り結果は未確認の下書きとして保存され、確認・修正してから連絡先として登録できます。保存した連絡先は検索、タグ絞り込み、CSV・vCardでの書き出しに対応します。

できること

端末内OCR名刺画像の文字を端末上で読み取り、内容を確認して保存。
裏面もまとめて管理表面・裏面の画像を使い、情報を補完して登録。
タグ付きアドレス帳複数タグ、検索、未確認の絞り込みで整理。
連絡につなげる電話、メール、地図、iPhone連絡先、フォロー予定へ。
商談と次の連絡相手の連絡先と商談、活動履歴、次の予定をまとめて管理。
持ち出せるCSV、vCard、画像付きバックアップを書き出し。
端末内に保存初期版は無料。名刺・商談・活動履歴を端末で管理できます。

保存とプライバシー

端末内OCRとローカル保存を基本に、連絡先・カレンダー・写真へのアクセスは利用者が機能を選んだときだけ求めます。

現在のバージョンは、アプリによるクラウド同期・自動iCloud Driveバックアップ・チーム共有・アプリ内課金を提供していません。保存や書き出しの扱い、削除、問い合わせ方法はプライバシーポリシーに記載しています。

よくある質問

無料版でも使えますか？

はい。初期版は無料で、名刺の読み取り、確認、端末内保存、検索、タグ、書き出し、基本フォロー、個人用の商談・活動記録を利用できます。将来の有料機能の提供条件は、提供開始時にご案内します。

OCRの結果はそのまま保存されますか？

読み取り途中の画像と結果は未確認の下書きとして保存されます。内容を確認・編集してから確認済みの連絡先として登録できます。

名刺データを別の端末でも使えますか？

画像付きバックアップを書き出し、別の端末のaftercardへ取り込めます。端末間の自動同期はありません。機種変更や紛失に備え、バックアップはご自身で保管してください。
