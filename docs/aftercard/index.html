紹介プライバシー利用規約

名刺を撮る。整える。あとで迷わない。

aftercardは、名刺を撮影または写真から読み取り、名前・会社・電話・メール・住所などをタグ付きの連絡先として保存するiPhoneアプリです。

読み取りは端末内OCRを基本にし、結果を確認してから保存できます。保存した連絡先は検索、タグ絞り込み、CSV・vCardでの書き出しに対応します。

できること

端末内OCR名刺画像の文字を端末上で読み取り、内容を確認して保存。
裏面もまとめて管理表面・裏面の画像を使い、情報を補完して登録。
タグ付きアドレス帳複数タグ、検索、未確認の絞り込みで整理。
連絡につなげる電話、メール、地図、iPhone連絡先、フォロー予定へ。
持ち出せるCSV、vCard、画像付きバックアップを書き出し。
保存場所を選べる無料は端末内保存。対応するクラウド保存は別途提供。

保存とプライバシー

端末内OCRとローカル保存を基本に、連絡先・カレンダー・写真へのアクセスは利用者が機能を選んだときだけ求めます。

クラウド保存を有効にした場合の送信範囲、削除、問い合わせ方法はプライバシーポリシーに記載しています。

よくある質問

無料版でも使えますか？

はい。名刺の読み取り、確認、端末内保存、検索、タグ、書き出しを利用できます。

OCRの結果はそのまま保存されますか？

読み取り結果を確認・編集してから保存します。誤認識を修正できる設計です。

名刺データを別の端末でも使えますか？

ローカルデータは端末内に保存されます。クラウド保存を利用する場合の同期条件は提供プランに従います。
