続けやすさを大切に、記録・予算・振り返りをひとつのアプリにまとめました。

01 / 記録

固定費も、日々の支出も

サブスクや光熱費から食費、日用品まで。生活にかかるお金をカテゴリごとに記録できます。

02 / 予算

今月の状況を見渡す

カテゴリごとに月次予算を設定。ダッシュボードで支出状況や予算の達成率を確認できます。

03 / 振り返り

月ごとの変化を確認

支出の内訳や前月との動きを振り返り、月次レポートを画像で共有できます。
