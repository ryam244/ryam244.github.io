01 / TODAY

行動時間、記録した日、週の目標、日ごとの進み方をまとめて確認。休む日も記録の一部です。

BEFORE YOU START

よくある質問

毎日続けられない人向けですか？

毎日同じ量をこなす前提ではありません。今日の時間と余力から量を選び直す設計です。習慣の定着や成果を保証するものではありません。

アカウント登録は必要ですか？

不要です。記録は端末内に保存されます。アプリ削除や端末故障で失われる可能性があるため、必要に応じてJSONバックアップを保存してください。

アプリ内AIは使っていますか？

使っていません。候補表示は、登録した目標・曜日・今日の時間・余力・週の進み具合をもとにしたアプリ内計算です。

料金はかかりますか？

現在の公開版は無料です。アプリ内課金やサブスクリプションはなく、自動的に課金が始まることもありません。

データは送信されますか？

習慣や記録を当方のサーバーへ自動送信する機能はありません。クラウド同期、広告、解析SDKもありません。バックアップの保存・共有先はご自身で管理してください。お問い合わせや本サイト閲覧時の情報については、プライバシーポリシーをご確認ください。

Webブラウザでも使えますか？

現在公開しているのはiOSアプリです。このサイトは紹介・サポート用で、ブラウザ版アプリは提供していません。
